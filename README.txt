نظام حضور الطلبة QR

المزايا:
- إضافة الطلبة برقم فريد.
- إنشاء QR لكل طالب.
- مسح QR بالكاميرا وتسجيل الحضور تلقائياً.
- منع تسجيل الطالب مرتين لنفس المادة والتاريخ.
- حساب الحاضرين والغائبين.
- سجل حضور حسب التاريخ والمادة.
- تصدير CSV ونسخة احتياطية JSON واستعادتها.
- يعمل كتطبيق PWA ويمكن تثبيته على الهاتف.

مهم: الكاميرا في المتصفح تحتاج HTTPS أو localhost. عند نشر الملفات على GitHub Pages أو Netlify أو استضافة HTTPS سيعمل المسح بالكاميرا.

هذه النسخة تخزن البيانات محلياً على الجهاز (localStorage)، لذلك لا تستخدمها بعدُ كنظام مركزي متعدد الأجهزة. للنسخة الجامعية/المدرسية النهائية نربطها بقاعدة بيانات وحساب مدرس ونسخ احتياطي مركزي.
